# Countdown: дистилляция Qwen3-4B в Gemma-3-1B

Задача Countdown: из заданных чисел и операций `+ - * /` собрать выражение, равное целевому числу. Каждое число можно использовать не больше одного раза.

```
nums = [19, 36, 55, 7], target = 65
55 + 36 - 7 - 19 = 65
```

Большая модель (Qwen3-4B-Instruct-2507) генерирует решения, маленькая (Gemma-3-1B-it) учится на них через SFT.

Результат: **91%** на лидерборде соревнования.

## Что сделано

1. 80k задач из [Countdown-Task-GOLD](https://huggingface.co/datasets/HuggingFaceTB/Countdown-Task-GOLD) прогоняются через teacher, ответы кешируются на диск.
2. Gemma-3-1B грузится в 4 бита (nf4), сверху LoRA на `q/k/v/o_proj` (r=16, alpha=32). Обучается около 3M параметров из 1B.
3. SFT через `trl`: 1 эпоха, батч 64, lr 1e-4, cosine, packing, bf16.
4. На инференсе ответ модели проверяется: числа должны быть из условия, значение должно совпасть с target (выражение считается слева направо, как в метрике). Если проверка не прошла, решение ищется перебором.

## Запуск

Нужна GPU с bf16, я запускал в Colab. Gemma - gated-модель, поэтому нужен токен HF с принятой лицензией.

```bash
pip install -r requirements.txt
export HF_TOKEN=...
```

Для инференса рядом с ноутбуком нужен `test_public.csv` (`id`, `nums`, `target`), на выходе `submission.csv` (`id`, `equation`).

Если в `competition_gemma/final_adapter` уже есть адаптер, обучение пропускается.
